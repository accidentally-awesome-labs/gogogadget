### Added

- **`/metrics`** — hand-rolled Prometheus text exposition (no new dependency),
  bearer-gated and unregistered in production without a token.
- **Audit retention** — `AUDIT_RETENTION_DAYS` drives a janitor pass; the
  default of 0 keeps everything.
- **Schedules admin** at `/admin/schedules` — create, toggle, run-now, delete,
  with run-now guarded so a disabled schedule cannot be sneak-fired.
- **Feature-flag admin** at `/admin/flags` — create, delete, and per-org
  overrides.
- **Docs search** at `/docs/search` — ranked results over the embedded
  markdown, with AND semantics and snippets.
- **Webhook secret rotation** with a 24-hour dual-signing grace window, so
  receivers can roll over without dropping deliveries.
- **Impersonation now requires a stated reason** (10–280 characters), stored
  on the session row and repeated in both audit entries.
- **OpenAPI 3.1** at `/api/v1/openapi.yaml`, embedded in the binary and kept
  honest by a route⇄spec parity test.
- **Cursor pagination** for `GET /api/v1/projects` — keyset over
  `(created_at, id)`, stable under concurrent writes where offset was not.
- **`Idempotency-Key` on API POSTs** — 24-hour replay, conflict detection, and
  a claim released on 5xx so a transient failure cannot poison the key.
- **Per-token rate limits** (`API_RATE_LIMIT_RPM`) keyed on the token row, so
  one client cannot spend another's budget.
- **Email digest** — a per-user cadence (off/daily/weekly) rolled up from
  in-app notifications, rendered by the worker and window-stamped.
- **Per-user theme and locale**, stored server-side: dark mode paints on the
  first byte on a new device, and digest emails speak the user's language.

### Fixed

- The `ADMIN_EMAIL` grant only fires on first sight of a user row, so a
  pre-seeded demo user could never reach `/admin` after a database reset.
- The per-IP rate limit is configurable (`RATE_LIMIT_RPM`); the hardcoded
  value was quietly failing test harnesses that drive one address hard.
- Deleting a feature flag now invalidates the evaluator cache, which had been
  serving the deleted flag as enabled for up to 30 seconds.
