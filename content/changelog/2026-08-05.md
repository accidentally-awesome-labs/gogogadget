### Changed

- **htmx 4.** Navigation swaps only `#content`, with attribute inheritance
  made explicit and configuration moved into the `htmx-config` meta tag. The
  shell is never a swap target, so clerk-js widgets and their body-level
  portals survive every page change.

### Fixed

- `worker-src 'self' blob:` — clerk-js runs its session handshake inside blob
  Web Workers, and without it authentication looped forever.
- The auth redirect chicken-and-egg, via an after-auth landing route.
- Organization mirrors are synced lazily from JWT claims, so a missed webhook
  no longer leaves a member without an org.
- Vendored the lazy clerk-js chunks (a CDN surprise must never reach
  production) and dropped a dead interest-cohort directive.
