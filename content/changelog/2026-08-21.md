---

### Added

- **Navigation progress.** Boosted navigation swaps only `#content`, so until
  the response landed the old page sat there untouched and a click looked like
  nothing had happened. A 2px progress bar and a dimmed content box now appear
  while a swap is in flight — after a 150ms delay, so a local navigation shows
  nothing at all and only a genuinely slow response draws anything.
- **`.skeleton`** for regions that load after first paint; the notification
  badge uses it to reserve its space so the bell no longer jumps sideways.
  There is deliberately no skeleton where content already exists — replacing a
  rendered table with a shimmering copy of itself is a downgrade.

Both respect `prefers-reduced-motion` by dropping the animation rather than
the feedback.
