### Added

- **Foundation** — stdlib config with boot-time validation, pgx pool, embedded
  goose migrations, sqlc queries (one file per table), and a seed command.
- **Web layer** — templ layouts, the load-bearing middleware chain
  (recover → requestID → accessLog → rate limit → secure headers → session →
  CSRF), and HTMX fragment helpers.
- **Identity (Clerk)** — session middleware behind a `Verifier` seam, route
  guards, and a webhook mirror that keeps users, orgs, and memberships local
  so every query stays a join away.
- **Billing (Polar)** — checkout, customer portal, webhook state machine,
  entitlements, and plan truth in one file.
- **Background jobs** — a Postgres queue with `SKIP LOCKED` claims, a 5-minute
  visibility timeout, exponential backoff, and a dead-letter path — plus the
  `Sender` mail seam that writes to `tmp/emails/` with no account configured.
- **Projects CRUD, audit log, activity feed, and the admin dashboard.**
- **Public API** — org-scoped Bearer tokens and `/api/v1`, the second
  transport over the same rules as the HTML app.
- **Content** — markdown blog and docs collections, goldmark rendering, RSS,
  and SEO basics.
- **Observability** — Sentry and PostHog, both env-gated behind seams.
- **Ship** — Dockerfile, compose, fly.toml, CI, and the e2e + visual harness.

### Fixed

- Unsigned webhooks are trusted only under `DEV_AUTH_BYPASS`.
- Form fragments swap into their container rather than the form element.
- The admin org plan badge reflects the entitlement, not the raw product key.
